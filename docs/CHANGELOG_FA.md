# گزارش اصلاحات نسخه 1.1.0

مبنای این نسخه، سورس قبلی Asteria (React + Express + SQLite) است؛ همه صفحات و بخش‌های مدیریت قبلی حفظ شده‌اند.

## اصلاحات

1. `scripts/bootstrap-vps.sh` اضافه شد: تشخیص مخزن موجود، نصب بار اول، آپدیت سرویس فعال یا ترمیم نصب نیمه‌تمام بدون تلاش برای clone دوم.
2. حفاظت از پوشه نامرتبط و جلوگیری از بازنویسی خودکار آن؛ بررسی تطبیق origin GitHub و دامنه موجود.
3. بکاپ آنلاین SQLite هنگام اجرای سرویس و بکاپ سازگار با WAL در حالت توقف سرویس؛ آرشیو فایل‌های آپلودشده.
4. `scripts/update-vps.sh`: ساخت Docker image پیش از تعویض کانتینر در حال اجرا، بررسی سلامت بعد از استقرار.
5. `scripts/install-vps.sh`: بررسی و نصب اجزای کمبود Docker، Docker Compose و Buildx (با حفظ Docker موجود) و روشن‌کردن daemon در صورت نیاز.
6. پاسخ مشخص سلامت `{"service":"asteria","status":"ok","version":"1.1.0"}` برای تشخیص سرویس صحیح.
7. اصلاح راه‌اندازی اولیه دیتابیس: محتوای نمونه پس از حذف توسط مدیر در راه‌اندازی مجدد دوباره ایجاد نمی‌شود.
8. اسکریپت‌های مشاهده وضعیت و لاگ سرویس‌ها اضافه شدند.
9. README و راهنمای نصب یک‌خطی GitHub/VPS بازنویسی شدند و CI برای آزمون اسکریپت‌ها و ساخت image توسعه یافت.
10. ZIP مخزن با فایل‌ها در **ریشه ZIP** بسته‌بندی شده؛ مناسب استخراج و انتقال مستقیم محتوای سورس به مخزن.

## آزمون‌های انجام‌شده

- پنج آزمون پایه دیتابیس موفق (از جمله ماندگاری حذف محتوای نمونه بعد از راه‌اندازی مجدد).
- آزمون نصب جدید، آپدیت سرویس فعال، ترمیم سرویس متوقف همراه با بکاپ، حفظ فایل موجود، رد دامنه متفاوت و رد مسیر نامرتبط موفق.
- آزمون بکاپ SQLite در حالت متوقف همراه با فایل‌های آپلودی موفق.
- بررسی نحو فایل‌های shell و Node.js، بررسی JSX با TypeScript parser، بررسی نحو فایل‌های YAML موفق.

## محدودیت‌های تست

دسترسی به registry.npmjs.org در محیط آماده‌سازی بسته با خطای `EAI_AGAIN` مواجه شد؛ اجرای `npm install`، `npm run build`، اجرای رابط در مرورگر و اجرای Docker روی VPS در این محیط **انجام نشد**. این موارد در CI GitHub و در سرور واقعی باید تأیید شوند.

## محدودیت‌های محصول

درگاه پرداخت، ایمیل تراکنشی/ریست رمز، تطبیق رزرو با تقویم و سایر موارد ذکرشده در `KNOWN_LIMITATIONS.md` همچنان جزو امکانات تکمیل‌نشده‌اند. این بسته به معنی تأیید آمادگی تجاری و امنیت نهایی سایت نیست.
