# گزارش تغییرات ASTERIA v1.2

## تأیید و پیاده‌سازی طراحی
- هدر و صفحه اصلی با تم سرمه‌ای عمیق، طلایی، بنفش و پس‌زمینه روشن.
- فونت آنلاین Vazirmatn / Inter (بدون اضافه کردن فایل فونت به پروژه)، دکمه‌ها و کارت‌های جدید.
- بازطراحی responsive؛ ناوبری ثابت پایین موبایل، لمس بهتر و چیدمان یک/دوستونه صفحات.
- بازطراحی ظاهر پنل و اضافه کردن کتابخانه رسانه شبکه‌ای.

## ویدئو و رسانه
- آپلود چندفایلی عکس و MP4/WebM عمومی از داخل پنل؛ نوار پیشرفت، نمای بندانگشتی و فیلتر.
- فایل خصوصی برای محصولات و دانلود بعد از خرید بدون تغییر.
- کتابخانه مستقل ویدئو با API و دیتابیس جدید `videos`، مدیریت انتشار و نمایش عمومی.
- اعتبارسنجی URL های YouTube، YouTube Shorts، youtu.be و Aparat؛ تبدیل به آدرس embed ثابت، بدون قبول HTML خام.
- پخش درون‌صفحه‌ای ویدئو در درس‌های مجاز و مقاله، و صفحه گالری `/videos`.
- امکان افزودن ویدئو به مقاله با extra.videoUrl و افزودن کاور از کتابخانه، ویدئوهای دوره پولی فقط در درس‌های دارای مجوز قرار گیرند.

## PWA و استقرار
- manifest دوزبانه، آیکون‌های 192 و 512 و maskable، صفحه آفلاین و Service Worker تولیدشده در build.
- عدم کش پاسخ API، فایل‌های آپلودشده و مسیرهای خصوصی.
- به‌روزرسانی نصب Docker بدون تغییر مسیرهای `storage/` و اسکریپت‌های v1.1.
- حد آپلود پیش‌فرض برای VPS: 200 MiB. برای سرویس بزرگ‌تر تنظیم منابع سرور و دیسک لازم است.

## وضعیت آزمون
- آزمون‌های DB و امن‌سازی URL پخش: موفق.
- بررسی syntax سرور و تولید آزمایشی Service Worker: موفق.
- build کامل React، اجرای Docker و آزمون موبایل با مرورگر: در این محیط اجرا نشده است؛ به npm و محیط استقرار نیاز دارد.
