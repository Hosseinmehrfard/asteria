# ASTERIA v1.3 — React | پنل مدیریت کامل | فارسی / انگلیسی | PWA

وب‌سایت دوزبانه آموزش، مقاله، ویدئو، محصولات و خدمات آسترولوژی با **React 19 + Vite، Express، SQLite، Caddy و Docker Compose**. طراحی الهام‌گرفته از پیش‌نمایش تأییدشده: سرمه‌ای تیره، طلایی، فیروزه‌ای و سفید؛ صفحات واکنش‌گرا و نسخه نصب‌شونده وب‌اپلیکیشن (PWA). طراحی مستقل است و کد سایت مرجع کپی نشده است.

## نصب یک‌خطی از مخزن GitHub روی VPS

تمام فایل‌های ZIP را در **ریشه شاخه `main`** مخزن `https://github.com/Hosseinmehrfard/asteria` قرار دهید و Commit/Push کنید. دامنه را به IP سرور متصل و پورت‌های TCP 80/443 را باز کنید. روی **Ubuntu 24.04** این دستور را با دامنه واقعی اجرا کنید:

```bash
sudo apt-get update && sudo apt-get install -y curl git && (set -o pipefail; curl -fsSL https://raw.githubusercontent.com/Hosseinmehrfard/asteria/main/scripts/bootstrap-vps.sh | bash -s -- example.com)
```

اسکریپت مخزن موجود `/opt/asteria` را تشخیص می‌دهد و از `git clone` تکراری روی پوشه غیرخالی جلوگیری می‌کند. فایل `.env` و دیتابیس و آپلودها نباید به GitHub فرستاده شوند. پوشه `storage/` روی VPS پایدار می‌ماند.

**ایجاد اولین مدیر (یک بار):**

```bash
cd /opt/asteria && docker compose -f compose.yaml -f compose.vps.yaml exec web node server/setup-admin.js
```

سایت: `https://example.com` · پنل: `https://example.com/admin`

## آپدیت / بررسی وضعیت / بکاپ

```bash
cd /opt/asteria && bash scripts/update-vps.sh
cd /opt/asteria && bash scripts/status-vps.sh
cd /opt/asteria && bash scripts/backup-vps.sh
```

دستور آپدیت ابتدا بکاپ می‌گیرد، سپس فقط با `git pull --ff-only` نسخه جدید را دریافت کرده و سرویس را مجدداً می‌سازد. بکاپ‌ها در `storage/backups` قرار می‌گیرند؛ نسخه خارج از VPS نیز نگهداری شود. عملیات آپدیت به مخزن تمیز و بدون تغییر فایل‌های تحت Git نیاز دارد.

## مدیریت کل سایت بدون ویرایش کد

مسیر **`/admin/studio`**: «صفحه‌ساز و طراحی»، فقط برای مدیر کل (`admin`). پس از ذخیره، داده‌ها در SQLite ثبت می‌شوند و در صفحه عمومی نمایش داده می‌شوند. هیچ فایل React برای تغییر روزمره لازم نیست.

- **بخش‌های صفحه اصلی:** افزودن، تکرار، حذف، مخفی/نمایان و جابه‌جایی؛ پشتیبانی از هدر، دسترسی سریع، مطالب ویژه، مقالات، ویدئو، خدمات، نقل‌قول، دوره ویژه، دوره‌ها، محصولات، کتاب‌ها، معرفی مدرس، بنیاد پژوهشی، مزیت‌ها، ابزارها، خبرنامه و بخش کارت‌های سفارشی.
- **هر بخش:** عنوان، زیرعنوان، شرح فارسی و انگلیسی، تصویر، دکمه، لینک داخلی، تعداد محتوای نمایشی و کارت‌های دارای تصویر/آیکون و لینک؛ انتخاب عکس از کتابخانه رسانه.
- **قالب:** تغییر زنده رنگ‌های اصلی، گردی کارت‌ها، فونت فارسی و انگلیسی، لوگو، تصویر هدر/صفحه اصلی، آیکون سایت؛ پیش‌نمایش ساده رنگ در خود صفحه‌ساز.
- **ناوبری:** افزودن، حذف، مرتب‌سازی و مخفی‌کردن لینک‌های منوی اصلی؛ ویرایش لینک‌های فوتر، کپی‌رایت و معرفی سایت به هر دو زبان.
- **بخش‌های محتوایی دیگر در پنل:** مدیریت مقالات، صفحات، محصولات، دسته‌ها، دوره‌ها و درس‌ها، خدمات، پرسش‌های متداول، نظرات و بنرها، کاربران و نقش‌ها، سفارش‌ها، تخفیف‌ها، رزروها، پیام‌ها، خبرنامه، آمار، تنظیمات و سابقه تغییرات.
- **کتابخانه رسانه `/admin/media`:** آپلود گروهی تصویر و MP4/WebM، جست‌وجو و پیش‌نمایش، لینک عمومی و فایل خصوصی قابل‌دریافت طبق مجوز. برای تصاویر جدید از گزینه «انتخاب از کتابخانه» استفاده کنید.
- **ویدئوها `/admin/videos`:** لینک YouTube/Aparat یا URL فیلم عمومی آپلودشده؛ عنوان و شرح دوزبانه، کاور و وضعیت انتشار. پخش تعبیه‌شده در صفحات عمومی و درس‌های مجاز؛ سیاست میزبان خارجی ممکن است مانع پخش شود.
- **تنظیمات عمومی `/admin/settings`:** نام سایت، اعلان‌ها، تماس، شبکه‌های اجتماعی، سئوی متنی و امکان ثبت‌نام.

**حدود صفحه‌ساز:** محتوای سایت، شکل صفحه اصلی، لینک‌ها و رنگ/فونت را بدون کدنویسی مدیریت می‌کند؛ ایجاد یک قابلیت نرم‌افزاری کاملاً جدید یا تغییر منطق پرداخت/مجوزها همچنان به توسعه کد نیاز دارد. لینک‌های صفحه‌ساز عمداً فقط مسیرهای داخلی سایت را می‌پذیرند.

## PWA، موبایل و دو زبان

وب‌اپلیکیشن از Manifest و Service Worker استفاده می‌کند. در HTTPS از مرورگرهای سازگار قابل نصب است؛ صفحات و فایل‌های استاتیک اصلی کش می‌شوند ولی اطلاعات حساب و API خصوصی کش نمی‌شوند. نام، رنگ قالب و آیکون اصلی PWA با تنظیمات برند پنل هماهنگ می‌شوند. فارسی RTL و انگلیسی LTR هستند و نسخه موبایل منوی پایین و چیدمان جداگانه دارد. فونت Vazirmatn و Inter از اینترنت بارگیری می‌شوند؛ فونت جایگزین سیستم نیز تعریف شده است.

## توسعه و آزمون محلی

Node.js 22.16 یا جدیدتر:

```bash
npm install
npm run setup-admin
npm run dev
npm test
npm run build
```

فرانت‌اند: `http://localhost:5173` · API: `http://localhost:4000/api/health`. برای نسخه تولیدی از `npm start` بعد از `npm run build` استفاده کنید. CI در GitHub Actions تست‌های سرور، ساخت React، بررسی PWA و Docker را اجرا می‌کند.

## محدودیت‌های مهم

درگاه پرداخت واقعی و ایمیل/پیامک تراکنشی وصل نشده‌اند. سفارش در انتظار تأیید دستی پرداخت می‌ماند. ویدئوی عمومی تعبیه‌شده و URL ویدئوی آپلودشده DRM یا محافظت در برابر بازنشر ندارد. نقشه تولد محاسبه نجومی/نمایش نمادین است، نه پیش‌بینی علمی. HTTPS و تنظیم صحیح DNS برای PWA و SSL ضروری است. نتیجه آزمون‌های محلی و CI باید پیش از استقرار تجاری بررسی شود.
