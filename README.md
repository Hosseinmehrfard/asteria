# ASTERIA 1.2 — React, Persian/English, Media Studio & PWA

وب‌سایت مستقل آموزشی/فروشگاهی آستریا با **React 19، Vite 8، Express، SQLite، Docker Compose و Caddy**. طراحی تأییدشده سرمه‌ای/طلایی/بنفش با فونت‌های آنلاین Vazirmatn و Inter، راست‌چین فارسی، چپ‌چین انگلیسی و رابط واکنش‌گرای موبایل. راه‌اندازی برای VPS با **Ubuntu 24.04** و دامنه دارای HTTPS.

## امکانات

- صفحات عمومی: خانه، مجله، فروشگاه، دوره‌ها، چارت تولد، خدمات/رزرو، تقویم ماه، کتابخانه ویدئو (`/videos`)، تماس، پرسش‌های متداول و حساب کاربری.
- **پنل مدیریت `/admin`**: داشبورد، محتوا و صفحات دوزبانه، تصویر شاخص از کتابخانه، فروشگاه، سفارش‌ها، درس‌ها و دوره‌های پولی، تخفیف، کاربران/نقش‌ها، رزروها، پیام‌ها، فایل‌های خصوصی، خبرنامه، گزارش‌ها، تنظیمات و لاگ.
- **کتابخانه رسانه `/admin/media`**: آپلود چند عکس و ویدئو با نمایش درصد پیشرفت، انتخاب/رها کردن فایل، جست‌وجو، فیلتر، پیش‌نمایش، کپی لینک و حذف توسط مدیر. فایل‌های عمومی MP4/WebM، PNG/JPG/WebP/GIF؛ فایل‌های خصوصی برای تحویل بعد از خرید.
- **استودیو ویدئو `/admin/videos`**: عنوان و شرح فارسی/انگلیسی، کاور، انتشار/پیش‌نویس، افزودن لینک YouTube یا Aparat، یا URL ویدئوی عمومی آپلودشده. ویدئو در سایت با پخش‌کننده تعبیه‌شده و بدون انتقال معمول به سایت خارجی نمایش داده می‌شود؛ امکان تعبیه وابسته به سیاست ارائه‌دهنده است.
- **PWA نصب‌پذیر**: manifest، آیکون 192 و 512، Service Worker برای فایل‌های استاتیک و صفحه آفلاین. API خصوصی، سفارش‌ها، فایل‌های آپلودشده و صفحات حساب در کش آفلاین ذخیره نمی‌شوند؛ محتوا و ویدئو برای مشاهده به اینترنت نیاز دارند.
- داده‌ها در `storage/` VPS باقی می‌مانند؛ آپدیت از GitHub مخزن موجود را مجدداً `clone` نمی‌کند.

## نصب یک‌خطی از GitHub روی VPS

ابتدا محتوای همین ZIP را در **ریشه شاخه main** مخزن `Hosseinmehrfard/asteria` جایگزین و commit/push کنید. دامنه را به IP سرور وصل کنید و پورت‌های 80/443 را باز کنید. سپس `example.com` را جایگزین کنید:

```bash
sudo apt-get update && sudo apt-get install -y curl git && (set -o pipefail; curl -fsSL https://raw.githubusercontent.com/Hosseinmehrfard/asteria/main/scripts/bootstrap-vps.sh | bash -s -- example.com)
```

اگر `/opt/asteria` از همین مخزن موجود باشد، اسکریپت از clone مجدد خودداری می‌کند؛ در صورت نصب قبلی، ابتدا بکاپ می‌گیرد. دسترسی به مخزن GitHub باید برقرار باشد.

**ایجاد اولین مدیر** (فقط یک بار، تعاملی در SSH):

```bash
cd /opt/asteria && sudo docker compose -f compose.yaml -f compose.vps.yaml exec web node server/setup-admin.js
```

سایت: `https://example.com` • پنل: `https://example.com/admin`

## آپدیت، وضعیت و بکاپ یک‌خطی

```bash
cd /opt/asteria && bash scripts/update-vps.sh
cd /opt/asteria && bash scripts/status-vps.sh
cd /opt/asteria && bash scripts/backup-vps.sh
```

اولین دستور **پس از push نسخه جدید به GitHub**، قبل از آپدیت بکاپ می‌گیرد و Docker را دوباره می‌سازد. بکاپ‌ها در `storage/backups` نگهداری می‌شوند؛ نسخه‌ای خارج از VPS هم ضروری است.

## توسعه محلی

Node.js >= 22.16:

```bash
npm install
npm run setup-admin
npm run dev
npm test
npm run build
```

React: `http://localhost:5173` • API: `http://localhost:4000/api/health` • اجرای تولیدی: `npm start` پس از build.

آپلود عمومی تا 200 MiB برای هر فایل در VPS مجاز است (با `MAX_UPLOAD_MB` قابل تنظیم تا سقف 500). ویدئوهای حجیم بهتر است در ارائه‌دهنده ویدئو میزبانی و با لینک embed منتشر شوند. آیکون‌ها و Service Worker هنگام `npm run build` آماده می‌شوند و HTTPS برای قابلیت نصب PWA در دامنه لازم است.

## محدودیت‌ها و کنترل کیفیت

- درگاه پرداخت واقعی، ایمیل/پیامک تراکنشی، بازیابی رمز ایمیلی، پخش ویدئوی خصوصی با DRM و رزرو قطعی جلوگیری‌کننده از تداخل، در این نسخه موجود نیست. وضعیت پرداخت در پنل دستی است.
- فقط **ویدئوهای عمومی** که در سایت آپلود شده‌اند، مستقیماً قابل پخش هستند؛ برای درس‌های پولی، مجوز متن/درس در سرور بررسی می‌شود ولی پیوند عمومی YouTube/Aparat قابل بازنشر است و حفاظت DRM ندارد.
- در صورت مسدود بودن YouTube/Aparat یا غیرفعال بودن embedding از سوی منتشرکننده، پخش تعبیه‌شده ممکن است کار نکند.
- آزمون‌های SQLite و تشخیص URL و تولید PWA در محیط ساخت موفق شدند. به علت در دسترس نبودن رجیستری npm، تست مرورگر و ساخت کامل Vite/Docker در این محیط انجام نشد. CI مخزن GitHub برای این آزمون‌ها تنظیم شده است.
